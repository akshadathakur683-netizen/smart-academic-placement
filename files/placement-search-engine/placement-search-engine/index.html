Data Structures

How the pieces connect: Trie → Inverted Index gives the skill matches. K-D Tree gives the range matches. Both lists are combined, then ranked.

Trie

A tree where each node is one letter. A path from the root spells a skill.

Used for: skill autocomplete and prefix matching.

Time: insert and search O(L), autocomplete O(L + size of the matches). L = length of the word.

trie.js

Inverted Index

Maps each skill to the list of student IDs who have it, like the index at the back of a book.

Used for: finding students for one or many skills quickly.

Time: O(1) lookup per skill.

invertedIndex.js

K-D Tree

A binary search tree that alternates between CGPA and test score at each level.

Used for: range filtering. Branches that cannot match are skipped.

Time: insert O(log n) on average. Range search about O(√n + k) when balanced, O(n) in the worst case.

kdtree.js

Ranking algorithm

Gives every candidate a score out of 100, then sorts from highest to lowest with insertion sort.

Used for: ordering the eligible candidates.

Time: O(n²) worst case, fine for a small list.
